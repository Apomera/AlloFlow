  • Your teacher keypair is created in this tab with standard public-key authenticated encryption (X25519 + HKDF-SHA-256 + ChaCha20-Poly1305). Student packets carry only the public key, which can seal results but cannot unlock them.
  • Each student QR code holds opaque encrypted data starting with AFQR1:. It is never a web link and cannot be read by a regular phone camera or by anyone without your private key file.
  • Nothing is sent. This page cannot connect to anything: the rule below tells the browser to refuse every connection, and the browser enforces it.
  • The camera is never turned on unless you press Start camera. Video stays in memory in this tab and stops as soon as you press Stop camera or leave this page.
  • Nothing is kept in browser storage after you close this tab. If you press Open in Add up results, the zipped results pass through temporary site storage in this browser and are deleted as soon as Add up results reads them.
  • Use a school-managed computer or tablet when collecting student results, and store any saved private key file in your private school folder.
  • This page runs without AI. There are no cookies and nothing to sign in to.
  • This page loads ten files, all from this site: the page itself, two stylesheets (packets.css, packets-qr.css), six scripts (packets-page.js, packets_qr_crypto.js, word_sounds_take_home_loader.js, packets_zip.js, packets_handoff.js, packets-qr.js) and the icon in the browser tab. It loads no fonts, no trackers and nothing from another site.
  • Like any website, the server that sends these files can see that your browser asked for them. It receives nothing else.

1

Create or load a teacher key

One key works for a lesson, week or class. Students' packets only get the public key; your private key unlocks their QR codes.

Sealing packets for another teacher? Paste their public key (AFPK1...)

A teammate or paraprofessional can seal packets in Step 2 using only the lead teacher's public key. No private key is shared.

Key ID: Private key not saved yet Public key only (for sealing packets)

Check that this 8-character Key ID matches the Key ID shown under a student's QR code.

Save the private key file in your private teacher folder if you plan to scan results later or in a new tab. Closing this tab clears the key from memory.

2

Attach your public key to packet files

Drop any practice file or check (.html), or a .zip folder of packets (including Windows, Mac, Drive or AlloFlow .zip files). Each packet stays 100% offline with connect-src 'none' and gains a Show sealed QR for teacher button at the end.

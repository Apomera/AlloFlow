How to confirm it

One file. Word Sounds practice is usually 0.5 to 2 MB. Vocabulary practice is about 180 KB, or about 0.4 MB for ten words with their recordings. Math and Symbol Runner files are about 150 to 300 KB. Works with no internet.

About Packets: who makes it, and how to report a problem.

What a packet is

A packet is one file that holds a short practice activity or a short check.

  1. You make one file

    Pick the activities and the words. The file is put together in your browser. Nothing is uploaded.

  2. A student opens it

    It opens in a web browser such as Chrome, Edge or Safari. The questions, the sounds and the scoring are inside the file, so it works with no internet. On a phone or tablet, the student opens it on Open a practice file or check.

  3. The student saves a results file

    At the end the student presses one button, Save my work. It saves a spreadsheet file (CSV), which you open in a spreadsheet: one row for each question.

Check it yourself

You do not have to take this page's word for it. Each point below can be checked in a practice file.

A practice file can

  • Play recorded words and sounds that are stored inside it.
  • In vocabulary files, read the words aloud with the voice built into the device, when the student presses Read aloud.
  • Score each answer on the student's own device.
  • Keep the student's place on that device, so they can stop and pick up later. Start over removes it.
  • Save a results file to that device when the student presses the save button.

A practice file cannot

  • Run AI. Nothing is generated when you make a file or when a student uses it. The spoken sounds were recorded ahead of time with two AI voices (Kokoro and Google Gemini).
  • Connect to the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Ask for an account, a password or an email address. The student types a code name or a first name. That is all.
  • Use the microphone or the camera, or set cookies.
  • Keep its answers hidden. The answers travel inside the file so that it can score them with no internet. A results file can be edited, and the check value in it shows accidental changes, not deliberate ones.
  • Run inside a file preview. The previews in Google Drive, Google Classroom and the iPad Files app do not run the file. The file then shows a note that asks the student to download it and open it in a browser. Reported, not yet tested by us.

How your school's IT person can verify it

  1. Open a practice file and press About this file. It lists what the file stores, what it saves and the rules it gives the browser.
  2. Open the same file in a text editor. Near the top is a Content-Security-Policy line that ends with connect-src 'none'. That is the rule that refuses every connection.
  3. Read the code. The file has one script that runs, plus one data block that describes the file. The script is not minified. The long runs of letters inside it are the recordings.
  4. Open the file with the browser's developer tools on the Network tab and complete it. No request leaves the device. Entries that start with data: are the recordings inside the file.
  5. Read the source. It is public: AlloFlow on GitHub, license AGPL-3.0.

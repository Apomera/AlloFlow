A check file can:

  • Give one try for each problem, with no hints. After the practice questions, the learner is not shown right or wrong.
  • Run a clock on the learner's device. The clock keeps going when the learner leaves the page, and it does not give time back.
  • Save a results file to that device when the learner presses the save button. The results file shows right and wrong and the expected answers: it is the teacher's record.

A check file cannot:

  • Run AI. Nothing is generated when you make a file or when a learner uses it.
  • Connect to the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Keep its answers secret. The answers are scrambled in the file, so they cannot be read just by opening it. This stops casual looking, not a determined person.
  • Make the teacher code more than a lock. The code keeps the answers screen inside the file closed. It is a lock on the screen, not secret writing.
  • Stop a learner from starting over. A new start is saved as a new try, and the count of tries is kept only in that learner's browser.

    For a learner with no device: the same problems in the same order, on paper. The answers and how to score them are on a teacher page, on a sheet of its own.

    Saved. What to do next

    1. Send the file to your learners the way you send any file: your learning platform, a shared drive or a USB drive.
    2. Each learner opens it in a browser, finishes the check and presses Save results as a spreadsheet file (CSV). They hand that file back to you.
    3. Add the results up on the results page, or open them in a spreadsheet. In AlloFlow: Class Analytics, Add take-home results.

    The answers screen inside the file opens with your teacher code. This page has not kept the code.

    To fill in a learner's code name for them: when the file is on a website or a shared link, add #learner=CodeName to the end of the link, for example #learner=BlueHeron7. It stays on the learner's device.

    About this page

    What this page keeps

    Your last choices are kept in this browser so that the page opens the way you left it: the check, the grade, the version and, for your own problems, the list, the title, the time limit and the skip choice. The teacher code is never kept: it is gone when you close or reload this page. Nothing is kept anywhere else.

    Where the checks come from

    • The three ready checks are the problem sets the AlloFlow app uses: fixed versions for each grade. Every learner who gets the same grade and version gets the same problems in the same order.
    • For your own problems, the answers are worked out in this tab by plain arithmetic. A division has to come out even.
    • Math Fluency counts each correct digit in its place, the way the app does. Its score is digits correct per minute.

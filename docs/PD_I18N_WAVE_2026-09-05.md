# PD catalog strings: 43 keys into 63 language packs (2026-09-05)

## What was wrong

`catalog_module.js` reads 112 `tr('catalog_*', fallback)` keys. 43 of them, all added by the
2026-08-23 PD overhaul (shelf, hours log, persona, branching, editor and filter strings), existed
only as English fallbacks in the code: they were absent from `ui_strings.js` itself and from every
language pack, so `dev-tools/insert_pack_keys.cjs` would have refused them ("NOT in ui_strings").

## What was done

1. The 43 keys were added to `ui_strings.js` (root and `desktop/web-app/public/`) as top-level
   entries in alphabetical position inside the existing `catalog_*` block, with the exact English
   fallback text from the module (the file round-trips through `JSON.stringify(_, null, 2)`, so the
   insertion is byte-stable).
2. `insert_pack_keys.cjs` gained `--section .` for root-level keys (it only addressed nested
   sections before). Its guarantees are unchanged: key must exist in ui_strings, placeholders
   preserved, brand terms preserved, `.bak` written, all four pack copies written.
3. Hand translations for all 43 keys were applied to all 63 packs through the tool
   (`lang/` and `desktop/web-app/public/lang/` are tracked; the two desktop build trees are
   written too). Every pack copy parses and carries every `catalog_*` key that ui_strings has.

Convention followed from the STEM waves: "My modules" is translated as a UI label, "PD" is
rendered as the local term for professional development, JSON/CSV stay as-is, and the JSON shape
example `{ "start": "...", "nodes": { ... } }` is kept verbatim.

## Languages to have a native reader check

Same list as the earlier waves, plus the ones with the least reference material:
acholi, chin_falam, chin_hakha, maay_maay, marshallese, hmong, karen, lingala, kirundi,
kinyarwanda, tigrinya, igbo, hausa, yoruba. For these the sentences were kept short and literal;
where a settled term did not exist (for example "remix", "module", "JSON") the English word was
kept rather than invented.

## Verification

- 63 of 63 packs complete for the 43 keys; no pack has more than two values identical to English
  (the identical ones are labels like "Remix" that stay in English by convention).
- `dev-tools/check_translation_keys.cjs` passes.
- PD catalog render, tier-2 polish and shelf suites green.

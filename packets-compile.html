  • Nothing is generated when you compile an activity or when a student uses it. The compiler parses your JSON locally, removes any prompt metadata, keys, emails, and external web addresses, and builds a deterministic single-file student packet.

A compiled activity file can:

  • Run Quiz, Cloze, Concept Sort, Timeline Sequence, Sentence Frames/DBQ Writing, Branching Adventure, Escape Room, or Anchor Chart Study Guide activities completely offline.
  • Strip all external links, remote image addresses, email addresses, markup tags, and AI prompt metadata before compiling, showing an explicit strip report in Step 2.
  • Support Practice or Check mode where applicable, Bilingual home-language directions, Station Mode reset, printable study posters, and CSV, JSON, or optional sealed QR results.

A compiled activity file cannot:

  • Run AI or call any model or server. All grading, puzzle locks, and branching paths are deterministic rules stored inside the file.
  • Connect to the internet or load remote images. The file tells the browser to refuse every connection, and the browser enforces it.
  • Send student work anywhere without the student saving or sharing the results file.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

      What this page keeps

      Your last pasted JSON draft and compiler choices are kept in this browser so you can return to them. Teacher codes and student code names are never kept. Nothing is sent anywhere.

      Supported activity compilers

      • Quiz and Cloze compile to deterministic offline practice or scrambled-answer check packets with keyboard shortcuts.
      • Concept Sort, Timeline Sequence, and Sentence Frames / DBQ compile directly through the offline Choice, Sort & Write adapters.
      • Branching Adventures, Connected Escape Rooms, and Anchor Chart Study Guides compile to self-contained interactive offline packets with clue tracking, puzzle locks, self-checks, and printable study posters.

A STEM lab file can:

  • Run an interactive Simple Circuit Lab, Data & Graph Explorer, or Geometry Area, Perimeter & Angle Lab completely offline with keyboard, pointer, and touch controls.
  • Run as Practice (with hints and optional adaptive reinforcement) or as a one-try Check with optional timer and teacher review code.
  • Show optional home-language directions, reading tools, Station Mode reset, and save results as CSV, JSON, or an optional sealed QR code.

A STEM lab file cannot:

  • Run AI. Nothing is generated when you make a file or when a student uses it.
  • Connect to the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Send student work anywhere without the student saving or sharing the results file.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

    About this page

    What this page keeps

    Your last lab settings, CSV dataset, and questions are kept in this browser so that the page opens where you left off. Teacher codes and student code names are never kept. Nothing is sent anywhere.

    How these Mini-STEM labs work

    • Simple Circuit Lab computes connectivity, total resistance, and current via deterministic series/parallel Ohm law arithmetic.
    • Data & Graph Explorer parses CSV rows locally, renders pure DOM/CSS Bar and Dot/Range charts, and computes count, min, max, range, median, and mean deterministically.
    • Geometry Lab measures exact unit-square area, orthogonal boundary perimeter, base/height right-triangle and rectangle dimensions, and angle measures offline.

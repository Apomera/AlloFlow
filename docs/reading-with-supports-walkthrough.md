# Reading with supports: a quick walkthrough

*Updated September 20, 2026. These controls are implemented in the current development version; availability on the public site or an installed desktop build depends on its release version.*

Keep the original reading available, add explanations around it, and use an adapted companion when it helps students work toward the lesson goal.

1. **Open your original.** In teacher mode, paste the passage into **Source Material**, or select the saved source you want. Choose **Read original with supports**. The reader opens the selected wording unchanged; this step does not need an AI call.

2. **Add word explanations.** Choose **Add word supports** for AI suggestions, if a provider is available. Review them for accuracy and meaning in context. You can also open **Review word supports → Add a word or phrase** and write your own explanation without AI. If a word occurs more than once, choose the intended occurrence and save the support.

3. **Adjust the supports.** Use **Review word supports** or an inline **Edit** control to revise or remove an explanation. Select **Always show in lighter view** for an explanation you want to keep visible. **Show glosses** switches explanations on or off; **Gloss density → Lighter** reduces clutter. Refreshing AI suggestions preserves saved teacher edits, pins, and removals for that reading.

4. **Add an adaptation only if useful.** Choose **Create adapted companion** to generate a separate version. Review it before sharing. Use **Original**, **Adapted**, or **Both** to switch views. Both places readings side by side on wider screens and stacks them on smaller screens. **Show changes** optionally marks wording differences; turn it off to see inline glosses in the comparison. Some long or cross-language comparisons cannot show change markings.

5. **Check the reading's purpose.** **Use in this lesson** identifies a Main reading or Supporting reading. Adaptations default to supporting readings. **Use for activities** selects the passage for subsequent activity generation; check **Based on** before generating a quiz or another resource. Keep the chosen task aligned with what students need to learn.

6. **Check what students receive.** Save your work. When creating an assignment, select the intended resources and inspect the saved-link delivery summary. A selected adaptation should travel with its matching original and reviewed supports. Choose **Test as student** and confirm that the correct passage opens, the original remains reachable, and the explanations appear as intended. If exporting, check **Include original reading** where offered and inspect the output.

For a first try, use a short passage containing an unfamiliar word. For example, keep “Upon the heath.” intact and add an explanation of *heath*. Open **Lighter**, listen with **Listen to original** or **Listen with glosses**, and compare the experience before adding more supports.

If a teacher control is missing, check teacher mode and that you are viewing the original or the original pane of Both. If **Adapted/Both** is absent, first create or select a matching companion. If all the new controls are missing, check the build version; deployment of these changes has not been confirmed by this walkthrough.

The [local classroom-journey check](../reports/novak-classroom-journey/README.md) documents the tested flow for developers. It uses mocked AI/audio and does not establish live model quality. Public community-library publishing of preserved readings remains a separate unfinished path; this guide covers reading, assignment preparation, and supported exports.

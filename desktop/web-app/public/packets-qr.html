This page runs without AI. No account. Keys, files and scanned QR codes stay in this browser tab. See the details Hide the details
  • Your teacher key is made in this tab. It has two parts: a public part, which goes into student files and can only lock results, and a private part, which only you keep and which unlocks them.
  • A code is locked, not signed. Only your private key can read it, and a code that was changed or cut short is refused. It does not prove which student made it, any more than a results file does.
  • For IT staff, the methods are standard ones: X25519, HKDF-SHA-256 and ChaCha20-Poly1305.
  • Each student QR code holds locked data that starts with AFQR1:. It is not a web link. A phone camera that reads it shows only scrambled letters; only your private key file unlocks it.
  • Every question the student was given is in the code and is counted. A long result leaves some details out to fit (the time on each question, or the words of some questions), and this page says so for that student. A result too long for one code is not shown as a code: the student saves the results file instead.
  • Nothing is sent. This page cannot connect to anything: the rule below tells the browser to refuse every connection, and the browser enforces it.
  • Reading a QR code happens in this tab. Where the browser has no QR reader of its own (Chrome and Edge on Windows, Safari on an iPad or iPhone, Firefox), the page uses jsQR, an open-source QR reader (Apache-2.0) kept on this site.
  • The camera is never turned on unless you press Start camera. Video stays in memory in this tab and stops as soon as you press Stop camera or leave this page.
  • Nothing is kept in browser storage after you close this tab. If you press Open in Add up results, the results pass through this site's storage in this browser and are removed when Add up results reads them. If that page never opens, the copy stays in this browser until the next time a file is handed over.
  • Use a school-managed computer or tablet when collecting student results, and store any saved private key file in your private school folder.
  • This page runs without AI. There are no cookies and nothing to sign in to.
  • This page loads eleven files, all from this site: the page itself, two stylesheets (packets.css, packets-qr.css), seven scripts (packets-page.js, packets_qr_crypto.js, word_sounds_take_home_loader.js, packets_zip.js, packets_handoff.js, vendor/jsqr-1.4.0.js, packets-qr.js) and the icon in the browser tab. It loads no fonts, no trackers and nothing from another site.
  • Like any website, the server that sends these files can see that your browser asked for them. It receives nothing else.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

Collect by sealed QR

Collect results at your desk without students handing in files. At the end of a file the student shows a QR code. It is locked, so that only your key can read it.

School-managed devices only: Scan and hold student results on a school-managed laptop or tablet, not a personal phone. Each QR code is locked data (not a web link) and stays inside this tab.

1

Make or load a teacher key

One key works for a lesson, a week or a class. Student files get only the public part. The private part, which you keep, unlocks their QR codes.

Making files for another teacher? Paste their public key (it starts with AFPK1)

A teammate can attach the lead teacher's public key to files in step 2. The private key is not shared.

Key ID: Private key not saved yet Public key only (for making files)

Check that this 8-character Key ID matches the Key ID shown under a student's QR code.

Save the private key file in your private teacher folder if you plan to scan results later or in a new tab. Closing this tab clears the key from memory.

2

Attach your key to practice files and checks

Drop a practice file or check (.html), or a .zip of them (made by Windows, a Mac, Drive or AlloFlow). Each file still refuses every connection (its rule says connect-src 'none') and gains a Show sealed QR for teacher button at the end. A file made with an older version of AlloFlow has to be made again first; the list below says so.

    Scan or paste each student's QR code

    At the end of a file, open Show my teacher (or For the teacher on a check) and press Show sealed QR for teacher.

    Camera or QR photo

    Point the device camera at the student's sealed QR code, or choose a photo or screenshot of it.

    Hold the student's screen close, so the code fills most of the picture, and keep it still for a moment. Each new student is unlocked by itself.

# Cell simulator inquiry and navigation pass

The hub now offers three question-led routes, each connecting three existing activities:
- Cell balance: inside the cell → transport pathways → osmosis experiment.
- Similarities and differences: cell structures → organism comparison → cellular processes.
- Movement: observe → compare → play.

The route guide provides a current question, direct activity focus, optional observation entry, editable recorded observations, pause/resume, and a downloadable text report. Notes stay in the current session. Recording evidence does not mark an answer correct, award XP, or imply mastery. Editing a recorded observation returns that step to a draft.

The visual pass adds responsive route cards, readable surfaces independent of the host background, consistent focus indicators, and a compact guide with collapsible writing and review panels.

Activity labels now reflect the current mode, including Osmosis Lab, Compare, and Library. Search also matches ideas such as water, mitochondria, and transport, while retaining the existing grade-based activity restrictions.

The large mission dashboard remains in Observe, Play, and Quiz. Research activities collapse optional quest progress so students reach the activity sooner. Active inquiry guidance remains visible when Focus study was previously selected.

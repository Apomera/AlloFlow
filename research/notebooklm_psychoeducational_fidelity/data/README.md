# Study Data Directory

No NotebookLM study outputs or human-participant data have been collected.

## Intended layout

- `templates/` — blank CSV structures committed with the protocol.
- `pilot/` — future pilot cases, source packets, outputs, and annotations.
- `confirmatory/` — future frozen confirmatory materials.
- `derived/` — script-generated analysis datasets; never edited manually.

Future data directories must preserve a separation among:

1. Structured synthetic case objects.
2. Human-readable source packets shown to NotebookLM.
3. Private gold-standard ledgers withheld from NotebookLM.
4. Untouched raw NotebookLM outputs and citation captures.
5. Human and preliminary AI annotations.
6. Script-generated analysis data.

Real student records, pseudonymized student records, and secure assessment items are prohibited under the current protocol.

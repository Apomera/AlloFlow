# Remaining remediation refinements

Read-only review of policy `20260909-5` after the previous fixes. Seventeen targeted local probes, including eight valid controls, identify eight remaining findings below. Nine probe cases reproduce a defect because the dependency-policy finding has two variants. Application code and prior evidence were not changed.

## Prioritized findings

1. **[P1] Image-based native labels can still be overridden.** A label containing an image with `alt="Student name"` gives its input that native name in Chromium. Adding `aria-label="Teacher name"` passes the strict gate and is returned by `aiFixChunked`. The label fallback uses `textContent`, which omits image alternatives and incorrectly treats the source name as empty. Extend name resolution to descendant alternatives and test it against browser accessibility names. [Source:10236](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/doc_pipeline_source.jsx:10236), [Source:10256](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/doc_pipeline_source.jsx:10256). Evidence: `image-label-overridden` in [live results](live/results.json).

2. **[P2] Table-level role downgrades remain possible.** Adding `role="list"` to a native table passes the strict gate even though Chromium now exposes a list. The table-level check only rejects `none`/`presentation`; the new effective-role handling applies to headers. Preserve effective table semantics as well. [Source:10191](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/doc_pipeline_source.jsx:10191). Evidence: `table-role-list` in [live results](live/results.json).

3. **[P2] Caption exponents can move between bases.** An existing caption can change from `x<sup>2</sup> plus y2` to `x2 plus y<sup>2</sup>` while keeping the same flattened text and script contents. The caption comparison records attachment only when the script is inside a link; caption removal then prevents later position checks. Preserve script attachment within existing captions before removing them from general text comparisons. [Source:10398](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/doc_pipeline_source.jsx:10398), [Source:10403](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/doc_pipeline_source.jsx:10403). Evidence: `caption-exponent-base-moved` in [live results](live/results.json).

4. **[P2] Export acceptance can pass hidden table data.** A table whose data row has `aria-hidden="true"` passes every baseline check with complete coverage. Chromium exposes the table and headers but zero data cells. DOM text and header exposure do not establish accessibility of the expected data. Verify exposure and relationships for required cells. [Export:87](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/dev-tools/document_export_at_acceptance.cjs:87), [Export:98](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/dev-tools/document_export_at_acceptance.cjs:98). Evidence: `table-hidden-data-row` in [export results](export/results.json).

5. **[P2] Export acceptance can pass a wrongly named header.** A TH retaining text “Student” but gaining `aria-label="Teacher"` passes the expected Student/Score table contract. Chromium exposes a column header named Teacher. Compare accessible header names to the contract as well as DOM text and role membership. [Export:73](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/dev-tools/document_export_at_acceptance.cjs:73), [Export:100](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/dev-tools/document_export_at_acceptance.cjs:100). Evidence: `table-header-name-overridden` in [export results](export/results.json).

6. **[P2] Revealing a duplicate can conceal loss from the original instruction.** A rendered checkpoint initially exposes “Do not open the valve.” with a second identical instruction hidden. Hiding the original “not” and revealing the duplicate still passes `text`, `visible`, and `exposed` with complete coverage. Chromium now shows and exposes both “Do open the valve” and “Do not open the valve.” Ordered word inclusion matches the second copy and loses the source occurrence's identity. Bind preserved visibility/exposure to source text occurrences or stable local anchors while retaining valid hidden-content restoration. [Rendered:13](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/dev-tools/rendered_document_fidelity.cjs:13). Evidence: `duplicate-instruction-masks-original-negation-loss` in [rendered results](rendered-results.json). Controls confirm ordinary negation loss fails and revealing a duplicate without source loss passes.

7. **[P3] Dependency policies disagree between checkers.** Inert XML script data and fully embedded image `srcset` both pass baseline export acceptance but make the unchanged rendered comparison unavailable. The rendered helper still uses the older inert-type allowlist and treats every `srcset` as unresolved. Native images load successfully without network requests. Share dependency classification and run the same positive/negative fixtures through both entry points. [Rendered:149](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/dev-tools/rendered_document_fidelity.cjs:149), [Rendered:150](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/dev-tools/rendered_document_fidelity.cjs:150). Evidence: `inert-xml-dependency-parity` and `embedded-srcset-dependency-parity` in [rendered results](rendered-results.json). An executable-script control is correctly unavailable in both.

8. **[P3] Canonically equivalent headings can be falsely rejected.** Composed “Café” fails the corresponding decomposed heading expectation even though the native text is canonically equivalent. Table expectations now normalize both sides, but heading equality and exact role/name lookup do not. Apply consistent NFC normalization to heading observations and expectations without compatibility folding. [Export:79](C:/Users/cabba/OneDrive/Desktop/UDL-Tool-Updated/dev-tools/document_export_at_acceptance.cjs:79). Evidence: `heading-canonical-equivalent` in [export results](export/results.json).

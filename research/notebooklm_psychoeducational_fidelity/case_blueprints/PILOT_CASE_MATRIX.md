## Coverage targets

Across the pilot set, include at least:

- Two cases with high numerical density.
- Three with deliberate informant disagreement.
- Three with deliberate missingness.
- Three requiring temporal integration.
- Two with language or cultural-context safeguards.
- Two in which the correct high-stakes response is to state that evidence is insufficient.
- Two with a clearly supported study-defined conclusion.
- One case in which a source contains an inaccurate belief that must be attributed rather than repeated as fact.

## Pilot purpose

Pilot cases are used to calibrate:

- Whether NotebookLM can ingest every source format reliably.
- Whether full-report outputs fit within the interface without truncation.
- Atomic-claim annotation time.
- Boundaries between partial support, unsupported inference, and omission.
- Severity judgments.
- Citation capture and inspection.
- Prompt-condition distinctiveness.

Pilot outcomes will not enter confirmatory performance estimates.

## Open design decisions

1. Whether eligibility simulation should use one fictional cross-case rule set or separate rules by referral category.
2. Whether all eight report sections should be required in every case.
3. Whether recommendations should be scored in the primary paper or treated as a separate exploratory domain.
4. Whether multilingual and cultural-context cases can be validated by reviewers with relevant expertise.

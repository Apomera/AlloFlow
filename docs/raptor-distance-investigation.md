## Scientific meaning

The selected human reference is 60 cycles/degree, the upper end of a published 30–60 range discussed in [Potier, Mitkus and Kelber (2018)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6125913/). The selected wedge-tailed eagle reference is 140 cycles/degree, within the 132–143 maxima reported in [Reymond (1985)](https://pubmed.ncbi.nlm.nih.gov/4090282/). These numbers are qualified examples, not universal species thresholds.

The chosen Gaussian filter retains 10% of a sinusoid's original modulation at its selected reference frequency. That curve and 10% convention are authored illustrations; neither is a fitted retinal model or a detection threshold. Lowering display contrast changes RGB stripe values around a fixed mean. It does not alter angular spacing or the high-contrast reference bands. The display is not luminance-calibrated and does not predict low-contrast or real-world prey detection. Resolving stripes, detecting an object, and identifying an animal remain different tasks.

For plaque width `w` and perpendicular distance `d`, the exact angle is `2 atan(w/(2d))`. Frequency is stripe pairs divided by that angle in degrees. Magnification uses the ratio of half-field tangents. Three.js's vertical camera field is calculated from the specified horizontal field and aspect ratio. Both filtered panels start from the exact same render; dimensions, illumination, camera, and source contrast do not change between them.

- All companions are included in the existing packaging list and mirrored under the desktop application.

This activity uses the shared asset catalog but adds no species behavior, shared clock, physics engine, or global perception policy.

## Plan exact conditions with explicit application

The fifteenth iteration adds an optional **Set exact conditions · Plan a controlled change** disclosure beside the existing sliders. Native numeric fields accept whole-metre viewing distance (40–300 m), stripe-pair count (4–20) and display contrast (10–100%). Each field has a visible label, units and allowed range. Typing creates a local plan; only **Apply values and go to prediction** changes conditions. The preview compares the plan with the live conditions, identifying unchanged conditions, a single changed factor and its held variables, or a comparison that changes several factors and cannot isolate one cause. When a pin is missing or differs from the current starter, guidance explains how to retain the correct baseline before applying. It does not reveal a predicted result.

Applying valid changed values uses the existing condition-update path once and moves focus to the prediction heading. Prediction, reveal, pinning, pixel measurement and recording remain explicit learner actions. Applying the same values moves focus without updating the scene or invalidating revealed evidence. An invalid submission identifies each offending field in text, associates its error with the control, and focuses the first invalid field after the errors render. Empty, fractional, nonfinite and out-of-range entries are rejected without clamping or rounding. A stable polite region summarizes submission feedback; the continuously changing preview stays outside it.

An unfinished plan retains its original condition key. Changing the live controls preserves all planned entries but prevents application until **Use current conditions** explicitly replaces them. Before a plan has been edited, the fields follow the current conditions. Loading or failed scenes allow local planning while withholding application; recovery guidance leads to the existing retry control. Resetting a plan performs no scene, capture, pixel-read or persistent-state work. Existing notebook text, pins, kept readings and saved results retain their established behavior and schemas.

## Compare the same measured pixel before and after

## Repair a comparison that changes several factors

A three-column table previews the pin and planned conditions, labels the chosen row **Keep current**, and labels the other controls **Use pinned**. Applying the plan restores the other controls from the pin while retaining the selected current value, producing exactly one changed control. This also works when the canned doubling or 25% actions are unavailable at the pinned limits.

Choosing a factor only updates a local plan. Applying uses the established settings path once, requires a ready scene, and moves focus to the neutral prediction heading after the new conditions render.

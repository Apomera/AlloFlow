Every downloaded starter packet can:

  • Run completely offline in one single .html file and pass inspection on Look inside a file.
  • Be reopened later in its maker page so you can edit items, add home languages, or add student code names.

A starter packet cannot:

  • Run AI or send student work over the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Require student logins, cookies, or third-party servers.

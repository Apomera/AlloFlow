Start where your environment fits.

AlloFlow is larger than a single hosted app. Gemini Canvas is the simplest educator entry when Google AI is available. The Cloudflare-hosted browser app provides install-free access but no embedded AI credential. Packaged Desktop builds add local engines and OS-backed key storage. Each edition makes a different tradeoff

The interface and many deterministic tools are shared, but AI access, storage, installation, and document data flow depend on the path you select.

What the Cloudflare “shell” actually is

Static delivery, not a hidden AlloFlow AI backend

Cloudflare Pages delivers the application shell, modules, and static assets. The public bundle intentionally contains no provider billing credential. It should not be described as free AI, a remediation service, a fully offline app, or a guarantee that all data stays on the device.

  1. 1. Cloudflare delivers the appThe browser receives static HTML, JavaScript, modules, and assets from the Pages site.
  2. 2. Your selected path handles dataOrdinary web configuration, including any provider key, is stored in that browser's unencrypted local storage; avoid shared or student devices and remove keys after use. AI requests go directly to the provider you configure.
  3. 3. Sharing can stay lightweightTeacher-prepared self-contained resource links can be decoded in the student browser without a student account or AlloFlow data backend.

Student AI is off by default in teacher-prepared shared resources

Optional student bring-your-own-key access must be explicitly authorized by the activity policy and pass connection and capability checks. The default shared-resource experience does not ask a student for an AI key.

Focused extension paths

Bring one workflow to the agent you already use

Portable remediation Skill

A small, review-required workflow for source-bound PDF remediation in compatible AI workspaces. The host sees the attachment; the bundled scripts do not call AlloFlow, Cloudflare, a remote MCP, or telemetry.

Local remediation MCPB

A 31-tool local Claude Desktop connector with an embedded companion Skill. Offline document tools keep document data local; setup and some export helpers can download public dependencies without intentionally sending document content. Each release is CI-built and ships with a checksum list, SBOM, and GitHub build-provenance attestation.

Institution-owned remote MCP

Code for a separate Cloudflare Worker, storage, durable workflow, and container architecture. It is intended for approved institutional pilots with OAuth, quotas, retention, and fail-closed delivery—not for the public Pages app.

Source-dependent tools

The finder tells you what to prepare before launch

Many AlloFlow resources work from a text, PDF, webpage, lesson, or prior analysis. Search results label whether you can start immediately, need to bring a source, or must analyze a source first. This keeps users from arriving at a powerful tool with no usable context.

  1. Start without a sourceOpen simulations, communication boards, reference tools, and selected deterministic activities immediately.
  2. Bring a sourceAttach or paste the article, document, lesson, or media that the selected tool will transform.
  3. Analyze, then createFor tools that depend on the shared content model, run source analysis first so downstream resources use the same evidence.

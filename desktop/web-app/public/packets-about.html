About

Packets makes short practice activities and short checks for students. Each one is a single HTML file that runs in a web browser with no internet connection. At the end the student saves a results file, and the teacher adds up the results in a spreadsheet or on the Add up results page.

Who makes it

AlloFlow, an open-source project. The code is public: AlloFlow on GitHub.

Report a problem or ask a question

Open an issue on GitHub: AlloFlow issues. Posting there needs a GitHub account, and what you post can be read by anyone.

Do not put student information in a report: no names, no code names, no results files and no pictures of a screen that shows them. Say what you did, what you expected and what happened instead, and which browser and device you used.

Student data

These pages have no accounts, no cookies and no analytics. A practice file or check keeps the student's place and answers in the browser on the student's device, and in any results file the student saves. Nothing is sent to this site, and a results file goes only where a person takes it. Optional sealed QR codes encrypt on the student's device and open only with the teacher's private key in Collect by sealed QR, with no internet. Standard practice files and checks never use the microphone; only a read-along file where the teacher turns on optional Student Voice Practice can ask for it, and audio stays in browser memory only. There is one exception for student files: a practice file made inside the AlloFlow app with a class mailbox sends the results to that teacher's mailbox when the student presses Send. A few teacher pages can reach another site, only when the teacher asks: Find a picture searches picture services, Look up a word online asks a dictionary, and the two pages that make recordings with a computer voice download the voice runtime and voice. The guide For school IT lists every one, and what each sends.

The approved changes are the nautilus eye subtrees and appended kelp leaf geometry. Existing shell, head, siphon, 90 tentacles, all other species, seagrass, plant placement and gameplay remain protected.

Before changing any expected fingerprint, the exact existing preservation callbacks and serializers in five suites were evaluated against the saved pre-change source, `baseline.generated.cjs`, with LF SHA-256 `370db22149565f8f90605053afb16190b121c2b4effb7781ff1c7276fdd1095e`. All **66 original fingerprint assertions matched**. These are fingerprint comparisons, not 66 test scenarios.

The new exclusions were then applied to those same serializers against that same original source. Only descendants of `cl-eye-rim`, `cl-iris`, `cl-pupil` and `cl-eye-highlight` under the root whose species is `nautilus` were removed. This changed six nautilus fingerprints; the other 60 fingerprint assertions remained identical. The migrated callbacks were evaluated again against the saved original source and matched. No candidate geometry was used to choose these expectations.

The older suites retain their previous shell exclusions. The new nautilus-eye unit suite independently protects the complete accepted shell and every other nautilus part. The shell suite's eye-clearance rays now target the actual opening boundary centroids instead of mesh attachment origins, preserving both viewing directions and all 17 shell-rocking angles.

Plant geometry migrations use the approved kelp vertex/triangle counts (57/72 → 141/168) and measure the central ribbon's apex via its existing section/column metadata. Appended leaf vertices no longer masquerade as the old ribbon's final row. All triangle, normal, grounding, bounds, resource and 525 seeded placement/height/yaw/phase assertions remain. The new frond unit suite supplies original-source grass byte parity and kelp central-ribbon prefix protection.

The first integrated unit batch (`unit-final.json/log`, despite the filename) reported **69 passed / 1 failed**. The old plant-flex normal oracle's central difference now reached central-stipe vertex 54, previously omitted as an end row. Its stored Y was `8.699999809265137` for height `8.7`; an upward `1e-5` probe crossed the shader's `t=1` clamp. Only this vertex failed, at three phases; all 159 interior samples had a minimum normal dot product of `0.9999999999999997`. The environment author independently confirmed inward second-order differences restore those tip comparisons to 1 within floating-point error.

The oracle now retains central differences whenever both probes remain in the physical height interval, and uses a signed second-order inward stencil at physical boundaries. It also samples the previously omitted root/final-tip rows, retains the strict `1 - 1e-9` normal threshold and the actual extracted production wave, and permits endpoint snapping only within a documented Float32 rounding bound. Production geometry, shader and all existing bounds/root/resource checks remain unchanged. Original failure evidence is retained; the isolated four-case rerun is saved separately in `plant-flex-recovery.json/log`.

The new `cephalopod-eyes-fronds.spec.ts` defines two serial, video/trace-disabled native GPU cases, one per low/balanced quality. They observe actual render callbacks for all six eye meshes, linked compiled programs and active position attributes, finite normal matrices, all 25 actual kelp meshes and 80 seagrass clusters, real `clPlantMotion` uploads, stable geometry/material/buffer identities, live motion, pause/inspection/reduced-motion behavior, resume and teardown disposal. The balanced case also projects the complete visible animal into phone framing. Camera assertions advance render-clock steps while simulation is paused, because camera smoothing deliberately uses raw render delta.

Fixture limits: the browser checks draw submissions and shader state, not pixel-level proof of a visible aperture or exact GPU-displaced vertex positions. The new CPU suites cover aperture rays, leaf attachment and shader-deformed bounds; root-owned visual captures assess appearance. Predators are held on cooldown and simulation advances only through counted clock steps. This fixture does not expand gameplay or collision scope. Integrated unit/browser outcomes belong in the root validation report; defining or listing a browser case is not a passing execution.

Authoring validation: the initial eight owned JavaScript/TypeScript files parsed using the repository's installed esbuild parser; Playwright listed exactly two new cases without starting the harness or browser (`browser-list.log`). The first parser command tried the absent `typescript` package and exited before parsing; switching to the already installed esbuild parser succeeded. The later plant-flex oracle migration was validated with its isolated four-case suite. No browser scenario was run by the test author.

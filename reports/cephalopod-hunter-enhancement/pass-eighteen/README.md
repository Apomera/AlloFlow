# Cephalopod Hunter — pass eighteen

Crabs now have shaped carapaces, raised eyestalks, bent segmented legs and open pincers. Rock, red and hermit variants read differently; the hermit carries a connected borrowed shell with a recessed opening. Clams now use two hollow valves with integrated concentric growth detail, restrained mineral tones and a posterior hinge that follows the existing drilling motion.

**46 distinct unit cases, four Chromium scenarios and nine matched visual views are validated.** After the final clam color polish, all five clam CPU cases and the low/balanced native pair were refreshed; unchanged cases are retained without double counting. The [validation summary](validation-summary.json) records each source hash and evidence stage. Native checks cover real render bindings, motion/pause/inspection, drilling/cancellation, capture/disposal, hermit shell drops and the existing reef mission.

Crabs keep their existing 11/15 mesh and material slots. Each clam drops from five meshes/four unique materials to two meshes/two independently owned materials. Static detail adds geometry; full measured costs are in the summary. Accepted cephalopod rigs, fish, den/coral/plant geometry, seeded behavior, hunting rewards and animation loops are byte-identical outside the guarded visual blocks. Four runtimes match. No FPS claim.

The models remain illustrative. Extra crab legs share an inherited gait slot; hermit whorl detail is subdued. The lower clam is half buried, so sand hides part of its interior.

This page runs without AI. No account. It sends your feedback to AlloFlow only when you press Send, and you see every word first. See the details Hide the details
  • This page can reach only one address: AlloFlow's feedback inbox at alloflow-catalog-submit.aaron-pomeranz.workers.dev. The rule below names that one address, and the browser refuses everything else, this site included. Standard practice files, checks, and the core maker and results pages never send anything to AlloFlow; see Guide for school IT for the few optional pages that can contact another host.
  • Nothing is sent when the page opens or while you type. A message is sent only when you check the box saying you have read it and press Send.
  • What is sent is exactly what the box "What will be sent" shows: the page you chose, the kind of feedback, your message after it was cleaned, and two words about your device (for example "Chrome" and "computer"). There is no name or email box, nothing can be attached, and this page reads nothing that other Packets pages keep in your browser.
  • Before you see it, the message is cleaned on this device: anything that looks like an email, a phone or ID number, a date, an address, a web link with details in it, a name, or a diagnosis is replaced with a word in brackets, such as [name]. The inbox checks again and refuses a message that still looks personal.
  • The inbox keeps each message for 30 days, then deletes it. It keeps no IP address, no browser details beyond those two words, and no location. Like any web request, yours passes through the hosting service, which sees your IP address as every website does.
  • This page runs without AI. The cleaning is a fixed set of rules in this page's script.
  • This page loads its own files from this site: the page, two stylesheets (packets.css, packets-make.css), three scripts (packets-page.js, word_sounds_wordlist_en.js, a word list that tells ordinary words from possible names, and packets-feedback.js) and the icon in the browser tab.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

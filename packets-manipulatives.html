A packet file can:

  • Run Base-Ten Blocks, Fraction Bars, Interactive Number Line, or Balance-Scale Equations offline in one file with full keyboard and touch support.
  • Offer optional deterministic hints, adaptive reinforcement, home-language directions, reading tools, and shared-device station mode.
  • Keep the student's place on that device, and save results as CSV, JSON, or an optional sealed QR code.

A packet file cannot:

  • Run AI. Nothing is generated when you make a file or when a student uses it.
  • Connect to the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Read other files on the student's device or send data without the student saving or sharing results.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

    About this page

    What this page keeps

    Your last choices and draft problems are kept in this browser so that the page opens where you left off. A student's code name and any teacher code are never kept. Nothing is sent anywhere.

    How these packets work

    • Every packet is assembled in this browser tab as one standalone HTML file with a strict zero-network policy.
    • All four manipulatives (Base-Ten Blocks, Fraction Bars, Interactive Number Line, and Balance-Scale Equations) run deterministically with full pointer, touch, and keyboard support.
    • Results save cleanly as CSV, JSON, or an optional offline Sealed QR code for teacher review.

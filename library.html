How to save and load a project

Explore the AlloPack library

63 topics · 125 pack versions. Open a pack to preview it, then choose Load in AlloFlow.

These AI-authored resources need educator review before teaching. Base and illustrated editions can contain different activities. Check the content, answer keys, accessibility, and source credits in the version you choose.

Using these packs in Gemini Canvas

Open the current AlloFlow Canvas and find the pack in its Community Catalog, or download the JSON file here and use Load Project. Pack links open the browser app; they do not automatically open a particular pack inside Google's shared Canvas.

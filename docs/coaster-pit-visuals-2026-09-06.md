# Illustrated physics pit stops

The Physics pit stop now uses three labeled SVG diagrams instead of the original decorative line sketches. Energy shows a supported descent and two car positions. Turns compares two explicit radii in a top view with equal entry-speed arrows. Airtime shows a crest, car, and near-zero seat-g readout. Every figure identifies its schematic view and includes a screen-reader description. The illustrations establish the scenario without giving away the multiple-choice response.

Energy, Turns, and Airtime use teal, amber, and violet accents respectively. Numbered progress markers become checkmarks with an explicit Explored label; the current idea also has a border and underline. Selected predictions have a visible side stripe, and keyboard focus has a dedicated outline.

A coaster emblem, stronger title hierarchy, framed diagrams, and a distinct Physics connection section make the learning cards easier to scan. The carried Build plan separates Change & compare from Evidence to collect using numbered sections. Activity headings have scroll spacing so keyboard focus keeps the icon and title below the sticky tabs. Illustrations use native SVG and introduce no animation or external assets.

Validation: 246 focused unit tests and both existing browser workflows passed. The energy, turn, and airtime diagrams and the phone layout were visually reviewed. The final browser capture uses a corrected harness height so scrolling does not move the app header outside the desktop preview.

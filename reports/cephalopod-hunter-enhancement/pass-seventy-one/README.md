## Practical limits

- Desktop Chromium, seeded starting layouts and emulated narrow viewport; no physical-device or frame-rate benchmark.
- Controlled positions at actual passage mouths; native keyboard input and scene geometry. Study cameras for scene screenshots.
- Predator motion has no body-sized rock collision; real rock rays provide directional cover, never refuge immunity.
- Illustrative passage clearances; finite site search skips a fully occupied start.
- Difficulty presets, shell assembly, transport gait and carried-shelter camouflage changes remain future work.
- Squeeze animation is illustrative: arm meshes do not solve full physical wall contact, and a tip can protrude beside the giant Pacific close-up.

Directional concealment is actual rock ray occlusion. A passage never sets a den flag or grants invulnerability. Open mouths remain visible and biteable; strikes through walls fail. Existing natural-gap sampling suggests nearby gaps were already common, but does not prove accessible entrance/retreat; authored passages add readable, validated routes.

## Proposed modes and portable shells

Keep Field study for observation, add Adventure for forgiving play, and develop Naturalistic behavior separately from numerical difficulty. A realistic preset should eventually use species-specific habitats, prey/scavenging, refuge selection, burial and defensive responses. These presets are not implemented in this pass.

Coconut octopuses carry shells beneath the body using an arm-tip stilt-walk, then assemble them as shelter when needed; carried shells provide no protection in the documented behavior. Plan collect → carry → deploy → hide, with distinct transport and shelter poses. Existing shelter assembly, gait and carried camouflage rules have not changed here. [Finn et al. (2009)](https://www.sciencedirect.com/science/article/pii/S0960982209019149)

See research.json for all twelve taxa, sources, confidence and uncertainty. Priorities are habitat-specific refuge opportunities, shell deployment, then sand burial.

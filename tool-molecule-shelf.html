Molecule Shelf

Explore real 3D molecular structures in Mol* — the viewer used by the world’s Protein Data Bank — from crambin and B-DNA to hemoglobin, an antibody, and the coronavirus spike. Rotate, zoom, and switch representations, with a Notice → Wonder observation coach beside it.

Open Molecule Shelf Opens the tool directly — no account, no signup, nothing to install.

Share this tool with a class or a colleague

This link opens Molecule Shelf on its own. Paste it into an assignment, a sub plan, a slide, or a message and it opens on the tool the student needs.

Where this fits

Molecule Shelf is one of the tools in the AlloFlow STEM Lab. AlloFlow is free and open source, and it runs in a browser.

Is there a manual for this tool?

Not yet. AlloFlow has written manuals for a few tools so far — see the manuals and guides page — and this one is not among them. The tool itself carries its instructions on screen.

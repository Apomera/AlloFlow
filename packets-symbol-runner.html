This page runs without AI. No account. Nothing you choose is uploaded. See the details Hide the details
  • Nothing is generated when you make a file or when a student uses it. The sets of symbols are fixed lists.
  • The sounds were recorded ahead of time with two computer voices made with AI: Google Gemini for letter names, letter sounds and common sight words, and Kokoro for the other words.
  • The file is put together in this browser tab. Your choices, the symbols you type and the pictures you add are not sent anywhere.
  • This page never uses the microphone. In the round on this page, the student answers by tapping, clicking or typing.
  • When a symbol has no recording, the round on this page can say it with a voice that is built into this device. It never uses an online voice.
  • There are no cookies and nothing to sign in to.
  • The page loads files from this site only. It gets the recordings of letters and sounds from this site too. Some words have their sounds in small files of about 40 words each, and the page gets only the ones your words need.
  • Like any website, the server that sends these files can see that your browser asked for them. That includes which of the small sound files were asked for, but not which words. It receives nothing else.
  • On this device the page keeps your last choices, and pictures you add are resized on this device and kept in the browser's shared My words database on this device. It never keeps a student's code name or a teacher code. The button that removes your choices is under About this page, at the bottom.
  • Open a file I made reads a file you saved before, on this device only. Nothing in it is run.

Make Symbol Runner practice

Quick naming practice, or a 1-minute check, for letters, letter sounds, numbers, words and dots. The student sees one card at a time and names it.

Start from a file you saved before. Then change what you want. You can also drop the file here. It is read on this device only.

Step 3 of 3

Make the file

The file is ready

The student sees it at the top of the file. The results file's name starts with it.

Saved. What to do next

  1. Send the file to your students the way you send any file: your learning platform, a shared drive or a USB drive. From Google Drive or Google Classroom, a student downloads the file first: the preview there does not run it.
  2. Each student opens it in a browser, does the practice or the check and presses the main button at the end, Save my work (in a check: Save results as a spreadsheet file (CSV)). They hand that file back to you.
  3. Add the results up on Add up results, or open them in a spreadsheet.

If the file does not open on a device (a phone, a tablet, or a school computer that will not open downloaded files), a student opens it on Open a practice file or check: apomera.github.io/AlloFlow/packets-open.html.

The answers screen inside the file opens with your teacher code. This page has not kept the code.

Put student code names in the file

Type 1 code name to put it into the file above, or 2 to 40 (one per line) to save one file per student in a .zip. In Google Classroom, where one assignment gives every student the same file, leave this empty and each student types a code name at the start.

Use code names or first names only, never full names. At most 40 at a time.

Sharing by web link instead? Add #learner=CodeName to the end of the link, for example #learner=BlueHeron7. It stays on the student's device.

About this page

What this page keeps

Your last choices are kept in this browser so that the page opens the way you left it: the kind of file, the set of symbols, how the student answers, the round's look, rehearsal, sounds and the title. A student's code name and a teacher code are never kept. Nothing is kept anywhere else.

Where the pictures and sounds come from

  • The built-in pictures are Mulberry Symbols and OpenMoji, under CC BY-SA 4.0, and simple drawings made for AlloFlow. A picture you add from this device is yours.
  • The sounds were recorded ahead of time with Google Gemini and Kokoro voices. Each practice file lists its credits under About this file.
  • In the file, rehearsal with known facts follows one fixed plan. Each new symbol comes with 1 known symbol, then 2, then 3, and once more at the end. The first time a new symbol comes, it is shown with its answer.

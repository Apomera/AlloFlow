Installing it, step by step

  1. Click the download button above. Your browser saves a file named something like AlloFlow-Desktop-setup.exe.
  2. Open the file when it finishes downloading. Windows will show a blue security screen. This is expected, and the next section explains exactly what to click.
  3. The installer opens. Choose where to install it, or accept the default, and click through.
  4. AlloFlow opens by itself when the installer finishes. After that it lives in your Start Menu.

The security warning, and why it appears

When you open the file, Windows shows a blue screen that says:

Windows protected your PC
Microsoft Defender SmartScreen prevented an unrecognised app from starting.

To continue, click More info, then click Run anyway.

This warning is not a virus alert and it does not mean anything is wrong with the file. Windows shows it for any program that has not been signed with a paid certificate from a commercial certificate authority. Those certificates cost several hundred dollars a year, and AlloFlow is independent software built by one educator rather than a company, so it is not signed yet.

If that gives you pause, that is a reasonable instinct, and you have two good options. You can skip the download entirely and use the web version, which needs no installation at all. Or, if your district has an IT team, you can hand them the file and this page, and they can review it and deploy it through your normal software process.

Prefer to avoid the download? Everything in AlloFlow runs in a browser at alloflow-cdn.pages.dev with no installation and no account. The desktop version exists for people who want files, models, and data to stay on their own machine.

What the desktop version adds

  • It works offline. Once installed, the tools run without an internet connection.
  • Your files stay local. Documents you open and work you save stay on your computer.
  • It can use local AI models instead of a cloud service, which matters for districts that do not want student work leaving the building.
  • Same-room sessions over your own network, without routing through anyone else's server.

Before you install

  • Space: the download is about 440 MB and the installed app needs roughly 1 GB. It includes the reading library, language packs, and the interactive labs, which is why it is large.
  • On a school-managed computer, you may not have permission to install software. That is normal and it is worth asking IT rather than working around it.
  • Which file: there is one Windows download and it is the right one for almost everyone, including newer ARM based laptops.

Mac and other systems

There is no Mac build yet. macOS applies stricter checks than Windows for unsigned software, so a Mac version needs an Apple developer account and a notarisation step before it would install cleanly, and shipping one that Macs refuse to open would help nobody. Until then, Mac and Chromebook users can run everything in a browser at alloflow-cdn.pages.dev.

If something goes wrong

  • Nothing happens when you open the file. Look for the SmartScreen window behind your browser, and check your Downloads folder to confirm the file finished downloading.
  • Your antivirus quarantines it. Unsigned installers are sometimes flagged automatically. Your IT team can allow it, or use the browser version instead.
  • The install is blocked entirely. Your computer is probably managed by your district, and software has to be deployed by IT.

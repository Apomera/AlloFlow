  • A word that is not in the word list can be looked up online, but not on this page: Look it up online opens a page of its own, which asks before it sends that one word to a free online dictionary.

  • On this device the page keeps your last choices and your changes to the questions. Pictures you add are resized on this device and kept in the browser's shared My words database on this device (never uploaded). The buttons that remove your choices and question edits are under About this page, at the bottom.

A file made here can:

  • Ask each question with four answers to choose from, in an order that is different for each question.
  • Read the word, the question and each answer aloud with the voice that is built into the student's device, when the student presses a button, or one after the other with Hear all. It uses only a voice that runs on the device. A word with a recording made ahead of time (a machine voice) plays that recording instead.
  • Show pictures, in picture questions you choose. They are in the file, with their credits.
  • Keep the student's place on that device, and save a results file to that device when the student presses the save button.

A file made here cannot:

  • Run AI. Nothing is generated when you make a file or when a student uses it.
  • Connect to the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Keep its answers secret. In practice they are inside the file, so that it can say right or wrong with no internet. In a check they are scrambled, which stops casual looking, not a determined person.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

      Saved. What to do next

      1. Send the file to your students the way you send any file: your learning platform, a shared drive or a USB drive. From Google Drive or Google Classroom, a student downloads the file first: the preview there does not run it.
      2. Each student opens it in a browser, finishes it and presses the main button at the end, Save my work. They hand that file back to you.
      3. Add the results up on Add up results, or open them in a spreadsheet. If your school uses AlloFlow, its Class Analytics reads these results files too.

      If the file does not open on a device (a phone, a tablet, or a school computer that will not open downloaded files), a student opens it on Open a practice file or check: apomera.github.io/AlloFlow/packets-open.html.

      The answers screen inside the file opens with your teacher code. This page has not kept the code.

      Kinds of questions
      More pictures and school concept diagrams
      Adds built-in diagrams for science, math, geography and reading words when the everyday picture set has none.

      Add or replace a picture for any word in your list with an image from this device (PNG, JPEG, GIF, WebP or SVG — resized on this device). Pictures are shared with My words on this device.

      Check the pictures

      Each word's picture comes first, then the 3 other pictures. A picture can show another meaning of a word. Leave out any word whose picture does not fit your unit. Picture questions cannot be answered with a screen reader.

      Check the sentences

      The wrong answers are other words from your list, so that only one word fits. Swap a word that could also fit.

      Practice or a check
      Without a code, the screen at the end shows only the score. With a code, it also shows each answer. It is a lock on the screen, not secret writing. 4 or more characters. This page does not keep the code, so write it down.
      More choices
      The student can hear the word, the question and each answer, read by the voice built into their device, one at a time or all in turn with Hear all. Only a voice that runs on the device is used. Devices with no such voice show no buttons.
      Many words have a recording made ahead of time, a machine voice, the same as in Word Sounds files. The file plays it for the word itself. The device voice reads the meanings and the questions. Recordings make the file bigger.
      Practice only. Each question the student missed on the first try comes back once, after the others. The results still show how the first time went.

      What is in the file

      Put student code names in the file

      Type 1 code name to put it into the file above, or 2 to 40 (one per line) to save one file per student in a .zip. In Google Classroom, where one assignment gives every student the same file, leave this empty and each student types a code name at the start.

      Use code names or first names only, never full names. At most 40 at a time.

      Sharing by web link instead? Add #learner=CodeName to the end of the link, for example #learner=BlueHeron7. It stays on the student's device.

      About this page

      What this page keeps

      Your last choices are kept in this browser so that the page opens the way you left it: the words, the kinds of questions, practice or check, the title, Read aloud and Recordings of the words. The teacher code and a student's code name are never kept.

      Your changes to the questions are kept too, so that the next file starts from them: the meaning you chose for a word, meanings and sentences you edited, wrong answers you swapped or edited, meanings you typed for words that are not in the word list, meanings you found with Look it up online, and words you left out of the picture questions. Nothing is kept anywhere else.

      Where the meanings come from

      • The meanings come from open dictionaries. They were shortened and cleaned up by a program when the word list was prepared, ahead of time. A file names its sources and their licenses under About this file.
      • Some meanings were checked and corrected with AI help when the word list was prepared, not by a person. They show AI-checked. Read the others first, and read every question before you give the file to students.
      • The recordings of words were made ahead of time with an AI voice (Kokoro). They come from the same store of recordings as Word Sounds practice.
      • The wrong answers are meanings of other words: related words from the word list, or the other words of your list. Fill the blank uses only words from your list, because related words often fit the sentence too.

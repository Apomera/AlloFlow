# Pass 41 hermit exterior shell finish proposal

The existing hermit shell is already a warm, vertex-colored spiral body with a dark open recess, a rolled lip and an embedded spire. The geometry is retained byte for byte. This proposal strengthens the exterior identity with restrained chestnut spiral bands, broad mineral mottling, a small weathering variation, fine growth striations at resolved viewing distances, and a physical roughness response. The rolled lip receives only 28% of the exterior tint effect so that it reads as worn cream. The dark recess remains entirely on its current material hook.

`proposal.cjs` contains two guarded replacements against accepted source SHA `73cc490a61ab9f2c0f85c8a0ab8478e242e7291a517148b5a3c3391b9ab09788`. It adds a single exterior material factory and replaces the existing constructor expression. The factory still constructs exactly one StandardMaterial per shell part. All four static material properties (color white, roughness .55/1, vertex colors, opaque) remain unchanged. The exterior shader adjusts physical diffuse color and roughness; it adds no lighting, emissive tint, normal/displacement changes, geometry groups, attributes, texture, mesh or material. One scalar piece uniform is allocated at compilation and never updated at runtime.

The vertex hook recovers the authored shell-root frame using the actual retained outer scale/translation or the lip/spire's X quarter-turn/translation. It deliberately does not divide by crab size: the original shell geometry builder does not use `sm` to scale its shell surfaces. Both whorl and spire use integer angular harmonics and a pole guard. Whorl bands follow the existing `turn - ny * 10.5` relief; spire bands use the existing spire's approximately 70.7-radian/metre spiral pitch. A +2π meridian turn leaves broad tint and fine lines periodic.

Fine growth lines require derivatives and fade out as their footprint becomes subpixel. The custom fallback omits those lines while retaining broad bands, mottling and roughness. This does not establish whole-device support for StandardMaterial without derivatives: bundled Three r128's existing lighting has its own requirements. Partial sentinel shader probes return before source or uniform mutation.

The portable CPU draft is `cephalopodlab_hermit_shell_finish.test.js` intended for the repository's `tests/` directory. It expects `restorePass41ShellSource` from `tests/helpers/cephalopod_pass41_reference.cjs`: generate that inverse from only this proposal's two replacements, enforcing exactly one matching `after` occurrence and reversing replacement order. A combined pass inverse can coexist with this narrower inverse. The three cases protect exact live construction/resources/RNG versus the literal inverse, exercise actual ShaderLib hooks and fallback guards, and independently compare every mapped exterior vertex with its real retained child matrix.

No tests, browsers, GPU captures or servers were executed by this agent. Root should review and run CPU checks, then verify actual native shader linking/uniform binding and paired shell views before accepting. The tint amplitude is intentionally moderate; if a paired native view still reads as overly plain, adjust shader coefficients through the proposal guard before final capture. No commit/staging/push was performed.

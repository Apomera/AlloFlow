A Maze file can:

  • Run a 3-minute timed (or untimed) CBM-Maze reading comprehension check with a 2-item warm-up sentence, pause/resume, and keyboard shortcuts (1, 2, 3), or run as immediate-feedback practice.
  • Show optional home-language directions, reading tools, and Station Mode reset between students.
  • Save results offline as CSV, JSON, or an optional sealed QR code with exact item counts for net CBM-Maze scoring.

A Maze file cannot:

  • Run AI. Nothing is generated when you make a file or when a student uses it.
  • Connect to the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Send student data anywhere without the student saving or sharing the results file.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

    About this page

    What this page keeps

    Your last passage, blank spacing, custom choices, and probe settings are kept in this browser so that the page opens where you left off. Teacher codes and student code names are never kept. Nothing is sent anywhere.

    About CBM-Maze scoring

    • Standard Curriculum-Based Measurement (CBM) Maze leaves the first sentence intact and turns every Nth eligible word (default 7th) into a 3-choice comprehension blank over a 3-minute reading window.
    • Net CBM-Maze score is computed as correct selections minus incorrect selections (with a floor of 0), while Practice mode offers untimed immediate feedback for instruction.

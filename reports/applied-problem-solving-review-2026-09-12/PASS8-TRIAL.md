# Pass 8 learner and teacher trial additions

Prepared September 19, 2026. No learner sessions have been conducted. Use these tasks with the existing LEARNER-TRIAL.md protocol, the learner's usual supports, and a teacher-reviewed challenge. The authored preview can test navigation; it cannot establish live AI quality or learning gains.

## Learner observations

1. **Start and consult the lesson.** Without showing the route, ask the learner to explain the task and begin. Then ask them to consult a lesson idea and return to their writing. Record time to first meaningful entry, missed controls, and whether the collapsed situation/reference panel is discoverable. Include a narrow screen with its keyboard open.
2. **Avoid repeating an explanation.** Give the learner a response that already explains the lesson connection, an untested check, a keep-or-revise decision, and a transfer example. Ask them to show where those ideas appear in the final review. Observe whether “I've explained this elsewhere” is understood and whether the location is useful to another reader.
3. **Recheck a changed passage.** Edit the response after saving a reference. Ask what “Recheck my reference” means and let the learner revise or remove it. Confirm they understand that identifying a location does not validate its quality or prove an experiment occurred.
4. **Capture a source without an organizer.** In the plain-notes preview, start from an open question, edit the proposed search query, and explicitly search. Choose one reference and explain how it supports or challenges the response. Check that existing notes remain, and ask what the unchecked-source label means. The preview search is mocked.
5. **Choose a response format.** Ask the learner to show how they would use a sketch, model, or recording. Observe whether they find the format choice and can identify a useful diagram label, slide, or timestamp. The current tool accepts a link and written explanation; AI does not inspect that link.
6. **Finish and recover.** Find the backup/restore menu, prepare a copy, and explain whether the work has been submitted. Use authored work to try restoration. Observe how learners interpret the device-storage status and whether a backup error remains visible.

## Teacher observations

Ask the teacher to choose a lesson idea, time, support, and task depth. Before generation, have them explain the selected settings and specify whether learners will plan a check or carry it out. After generation, compare the proposed product with the time and materials available.

Give the teacher two equivalent responses: one completed across the organizer fields, and one with reasoning in a single response and learner-created references. Ask them to locate the same four ideas in each. Record review time, missing or ambiguous references, and differences in how they judge the reasoning.

## What to decide afterward

- Simplify labels or placement if multiple learners miss the same action.
- Revisit the location-reference interface if learners provide locations another reader cannot find.
- Consider structured citations or teacher-selected source collections if source handling still consumes substantial task time.
- Audit shared recording/drawing tools before adding a new media-specific workflow.
- Run the prepared synthetic AI matrix once a provider is accessible. The September 19 execution-environment readiness check still reports a missing credential and zero model calls.

These observations can guide the next interface iteration. They are not an evaluation of educational effectiveness.

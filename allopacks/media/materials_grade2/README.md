# Materials Grade 2 artwork

24 original images generated with the built-in image tool: 10 glossary pictures and 14 lesson panels. All selected artwork was visually reviewed and is text-free. Labels and captions are native editable AlloFlow fields.

manifest.json preserves exact generation prompts, source paths, final filenames, reviewed alt descriptions, and label anchors. PNG files preserve generated artwork; WebP files are optimized versions embedded in the downloadable pack. embedded-assets.json records image dimensions and native alt hashes.

Build: node dev-tools/build_materials_illustrated.cjs
Integration QA: node dev-tools/qa_materials_illustrated.cjs
Focused tests: tests/allopack_materials_illustrated.test.js

See docs/MATERIALS_ILLUSTRATED_REVIEW.md for content refinements, verification, and publication scope. Educator review remains pending.

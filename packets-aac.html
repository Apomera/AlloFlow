An AAC board file can:

  • Open immediately as a Fitzgerald-key Core and Fringe communication board with an interactive sentence strip, Speak sentence, Backspace, and Clear controls.
  • Play optional embedded teacher audio clips or speak aloud using only a voice built into the device, with adjustable rate, mute toggle, and a visible note if no local voice is available.
  • Support touch, pointer, 2D arrow-key navigation, single-switch auto-scan, two-switch row-column step-scan, home-language family directions, paper backup printing, and optional non-scored carryover logging.

An AAC board file cannot:

  • Run AI or send spoken text to a cloud voice service. Only voices installed on the device or clips embedded in the file are used.
  • Connect to the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Record audio, open the camera, or send anything to anyone without a person explicitly saving and sharing an optional carryover log.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

    About this page

    What this page keeps

    Your last text board layout, folders, and button labels are kept in this browser so you can return to them. Learner code names are never kept. Nothing is sent anywhere.

    How these offline AAC boards work

    • Fitzgerald-key semantic categories color-code Pronouns (Yellow), Verbs (Green), Nouns (Orange), Describing/Feelings (Blue), Social (Pink), and Questions/Other (Purple) with high-contrast text and forced-colors borders.
    • Speech output plays optional embedded clips or uses only local on-device voices (never cloud speech engines) and shows a clear visual note whenever speech is muted or no local voice is installed.
    • Built-in 2D arrow-key navigation plus single-switch auto-scan and two-switch row-column step-scan run deterministically with no network dependency.

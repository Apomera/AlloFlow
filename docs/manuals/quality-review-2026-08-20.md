# Manuals and guides quality review — August 20, 2026

## Outcome

All current user-facing documentation now has one public discovery point in `manuals.html`, a governed inventory in `docs/manuals/catalog.json`, and audience paths for families and multilingual learner teams. The hub is linked from the shared promotional navigation and footer. The Teacher Guide, evaluation manual, and Dynamic Assessment guide now return readers to the central hub.

## Current strengths

- **Teacher Guide:** strongest general-purpose source. It is generated from 24 canonical chapters, searchable, printable/offline, and organized by task paths.
- **Educator Growth & Evaluation Manual:** strongest standalone illustrated manual. It has role-based starting points, a full contents list, accessibility controls, print behavior, and current workflow screenshots.
- **Dynamic Assessment Studio Guide:** strong specialist depth and responsible-use limits. This review added navigation, metadata, a review status, and more precise IDEA consent/eligibility wording.
- **Family and multilingual support:** useful material already existed but was easy to miss. The hub and Teacher Guide now expose both as first-class paths without claiming that separate full manuals are finished.
- **SEL Hub Educator Guide:** unusually candid boundaries and crisis cautions. This review removed brittle promises about ephemeral storage and fixed Google age/privacy guidance so administrators must verify the actual account, license, protection status, and retention settings.

## Highest-value remaining improvements

1. **Finish the 22-resource example set.** Keep the clean left-panel screenshots. Recapture result views marked replace in the screenshot quality audit, beginning with STEAM, Assess, Adventure, Concept Sort, DBQ, Activity Ideas, Glossary, Visual Organizer, and Anchor Chart.
2. **Complete three missing finished-result flows.** Text Adaptation, Word Sounds, and Interview Mode still need successful end-state examples before the guide can claim complete visual coverage.
3. **Create a family manual only when the workflow grows beyond Family Mode.** The first version should cover setup choices, home privacy, saving and moving work, teacher-to-family handoff, troubleshooting, and age-appropriate AI decisions in family language.
4. **Create a multilingual learner implementation guide when there is an owner for ongoing review.** It should combine output-language settings, translation review, home-language dignity, family communication, access-contrast limits, accessibility checks, and worked classroom examples.
5. **Generate specialist HTML from canonical sources.** The Dynamic Assessment HTML currently mirrors a Markdown source manually, and the SEL guide is Markdown-only. A small deterministic builder would reduce drift and give both guides consistent navigation, metadata, and print behavior.
6. **Add visible review ownership.** Dates now exist in the major specialist guides; the next governance pass should name the role responsible for product accuracy, accessibility, and high-stakes policy review.

## Publication boundaries

- Internal test plans, remediation fixtures, handoff notes, language-pack instructions, QA reports, and developer guides are not public manuals and should not appear in the catalog.
- A promotional overview is not a manual unless it supports a complete user task.
- A future idea may be named as planned, but it must not receive an active public card until a usable destination exists.

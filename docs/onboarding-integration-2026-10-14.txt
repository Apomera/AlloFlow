Prepared example storage
The fixed photosynthesis passage and display-only example analysis ship in the
Guided view module; translated UI text lives in ui_strings.js. No AI request,
history entry or completed-step record is created by opening the example.
Only the exact unchanged example passage may display its prepared analysis.
Choosing the example passage fills the ordinary editable source field, so the
existing source-draft autosave still applies; the prepared output is not saved.
This is an onboarding demonstration, not an imported Community Catalog lesson.

Intentional adaptations
- Explicit Continue last workspace instead of automatic adult-role selection.
- Visible independent-learning entry and concrete Professional tools label.
- Suggested reading-support path, optional Change path, no required AI planner.
- Source review always waits for Continue; auto-advance defaults off for users
  without an existing preference.
- Family opens source and support configuration without automatic generation.
- Quick groups are optional, use existing grade/language choices, preserve a
  refused-save draft and do not automatically replace current generator settings.
- Existing custom Guided progress, reader work and document-only controls stay.

Known limits and follow-ups
The local preview deliberately blocks external services. Its captured console
errors include blocked CDN fonts, audio and Chart.js. The visible diagnostic
badge was traced to a blocked kokoro-js dynamic import during the Family greeting,
not an onboarding exception; the report retains that diagnostic without hiding it.
The existing workspace AlloBot avatar can overlap the header menu, particularly
on mobile. Complete AlloBot styles were included in QA; its unchanged positioning
is outside this integration. The existing generated-resource auto-advance timer
also does not cancel a pending advance if its preference is toggled off mid-delay.
Neither follow-up was introduced by this selective integration.

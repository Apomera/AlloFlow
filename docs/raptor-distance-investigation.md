# Find the distant detail

Added 22 October 2026 as an opt-in investigation inside **Raptor Lab → Acuity Demo**. Open **Open distance investigation** beneath the existing visual-angle activity. Existing navigation, visual-angle settings, flight scale, controls, rewards, and lessons keep their previous behavior.

## Investigation

The learner changes distance (40–300 m), stripe pairs (4–20), and display contrast (10–100%). A fixed 30 cm plaque and an unchanged native catalog dove occupy one static meadow. The dove retains its authored metre scale and illustrative anatomy. A wide view supplies context; both detail panels have the same 0.75° horizontal field and approximately 26.9× magnification relative to the wide view. The near crop focuses on the plaque and excludes the neighboring dove; camera fitting never changes distance or object scale.

Learners predict the plaque's spatial-frequency band, reveal the comparison, and write an observation. Near, middle, and far presets cover all three reference bands. Changing conditions invalidates the prediction and reveal. The latest six saved observations retain their conditions, original prediction, model version, reference values, and the learner's own text. No reward or score is awarded for personal visual reports.

## Scientific meaning

The selected human reference is 60 cycles/degree, the upper end of a published 30–60 range discussed in [Potier, Mitkus and Kelber (2018)](https://pmc.ncbi.nlm.nih.gov/articles/PMC6125913/). The selected wedge-tailed eagle reference is 140 cycles/degree, within the 132–143 maxima reported in [Reymond (1985)](https://pubmed.ncbi.nlm.nih.gov/4090282/). These numbers are qualified examples, not universal species thresholds.

The chosen Gaussian filter retains 10% of a sinusoid's original modulation at its selected reference frequency. That curve and 10% convention are authored illustrations; neither is a fitted retinal model or a detection threshold. Lowering display contrast changes RGB stripe values around a fixed mean. It does not alter angular spacing or the high-contrast reference bands. The display is not luminance-calibrated and does not predict low-contrast or real-world prey detection. Resolving stripes, detecting an object, and identifying an animal remain different tasks.

For plaque width `w` and perpendicular distance `d`, the exact angle is `2 atan(w/(2d))`. Frequency is stripe pairs divided by that angle in degrees. Magnification uses the ratio of half-field tangents. Three.js's vertical camera field is calculated from the specified horizontal field and aspect ratio. Both filtered panels start from the exact same render; dimensions, illumination, camera, and source contrast do not change between them.

## Implementation and ownership

- `raptor_distance_model.js` supplies pure mathematics, strict settings normalization, presets, and source metadata.
- `raptor_distance_scene.js` owns one offscreen WebGL renderer, the native catalog dove, and its own environment. It renders on demand with no animation loop. Native resource disposal remains with the dove provider.
- `raptor_distance_study.js` supplies the accessible controls, prediction/reveal sequence, and notebook. State lives only in `raptorHunt.distantDetailStudy`, independently of existing `acuity`, flight sessions, and rewards.
- The invitation loads these companions only when opened. Closing during loading prevents late scene creation. Closing an active study disposes its renderer and native model; retry paths release failed scenes.
- All companions are included in the existing packaging list and mirrored under the desktop application.

This activity uses the shared asset catalog but adds no species behavior, shared clock, physics engine, or global perception policy.

The fifth iteration adds **Range-finding challenge · Map the distance bands**. Learners choose the selected human or eagle spatial-frequency reference, hold twelve stripe pairs and 95% display contrast fixed, and collect revealed trials at distances of their choice. The task is to bracket the reference crossing with a sample at or below it and another above it, narrowing the distance interval to ten metres or less. This brackets a model reference; it does not measure eyesight or prey detection. A static scatter plot shows only collected points and the selected reference line, with a parallel accessible table retaining original predictions. The graph never supplies an unmeasured crossing or a fitted curve.

Trial collection requires revealed conditions that match the scene diagnostics. A failed PNG copy does not invalidate a numeric trial when its original canvases are revealed.

This page runs without AI. No account. Nothing you choose leaves your device. See the details Hide the details
  • Nothing is generated when you make a file or when a student uses it. The meanings come from a word list that was prepared ahead of time from open dictionaries. Where they come from is under About this page.
  • The file is put together in this browser tab. Your words, your changes and the teacher code are not sent anywhere.
  • The page gets the word list from this site, all of it at once: the same files whatever words you type. For a file with recordings or pictures it also gets them from this site: the recordings of your words, and all the picture files, the same files whatever words you type. It asks the network for nothing else, and the rule below tells the browser to refuse anything else.
  • A word that is not in the word list can be looked up online, but not on this page: Look it up online opens a page of its own, which asks before it sends that one word to a free online dictionary.
  • There are no cookies and nothing to sign in to.
  • Like any website, the server that sends these files can see that your browser asked for them. It receives nothing else.
  • On this device the page keeps your last choices and your changes to the questions. The buttons that remove them are under About this page, at the bottom.

A file made here can:

  • Ask each question with four answers to choose from, in an order that is different for each question.
  • Read the word, the question and each answer aloud with the voice that is built into the student's device, when the student presses a button, or one after the other with Hear all. It uses only a voice that runs on the device. A word with a recording made ahead of time (a machine voice) plays that recording instead.
  • Show pictures, in picture questions you choose. They are in the file, with their credits.
  • Keep the student's place on that device, and save a results file to that device when the student presses the save button.

A file made here cannot:

  • Run AI. Nothing is generated when you make a file or when a student uses it.
  • Connect to the internet. The file tells the browser to refuse every connection, and the browser enforces it.
  • Keep its answers secret. In practice they are inside the file, so that it can say right or wrong with no internet. In a check they are scrambled, which stops casual looking, not a determined person.

The rule this page gives your browser. The browser refuses anything the rule does not allow: It is the Content-Security-Policy line near the top of this page's source.

      Without a code, the screen at the end shows only the score. With a code, it also shows each answer. It is a lock on the screen, not secret writing. 4 or more characters. This page does not keep the code, so write it down.

      Saved. What to do next

      1. Send the file to your students the way you send any file: your learning platform, a shared drive or a USB drive.
      2. Each student opens it in a browser, finishes it and presses the main button at the end, Save results as a spreadsheet file (CSV). They hand that file back to you.
      3. Add the results up on Add up results, or open them in a spreadsheet. In AlloFlow: Class Analytics, Add take-home results.

      On a phone or tablet, a student opens the file on Open a practice file: apomera.github.io/AlloFlow/packets-open.html.

      Make one for each student

      One file for each student, with the student's code name filled in. They come in one .zip file. Each file is the same as the one above, made with that code name.

      Use code names, not real names. At most 40 at a time.

      About this page

      What this page keeps

      Your last choices are kept in this browser so that the page opens the way you left it: the words, the kinds of questions, practice or check, the title, Read aloud and Recordings of the words. The teacher code is never kept.

      Your changes to the questions are kept too, so that the next file starts from them: the meaning you chose for a word, meanings and sentences you edited, wrong answers you swapped or edited, meanings you typed for words that are not in the word list, meanings you found with Look it up online, and words you left out of the picture questions. Nothing is kept anywhere else.

      Where the meanings come from

      • The meanings come from open dictionaries. They were shortened and cleaned up by a program when the word list was prepared, ahead of time. A file names its sources and their licenses under About this file.
      • Some meanings were checked when the word list was prepared. They show the word checked. Read the others before you give the file to students.
      • The wrong answers are meanings of other words: related words from the word list, or the other words of your list. Fill the blank uses only words from your list, because related words often fit the sentence too.

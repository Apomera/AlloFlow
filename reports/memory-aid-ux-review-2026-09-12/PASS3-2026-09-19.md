# Memory Aid — revision drafts and useful private history

This pass improves the transition from self-checking to revision and makes earlier work easier to recover.

- **Revision ideas save privately as drafts.** Typing a revision idea saves it with the completed attempt. The draft survives reload and remains separate from a committed revision goal. “Save goal and revise cue” is still the explicit action that commits the goal and opens cue editing.
- **Next steps reflect the self-check.** When facts need more practice, the revision section appears before the application exercise, with guidance to choose a connection to strengthen. A completed self-check with no flagged facts offers application or later review without implying mastery.
- **Private history retains useful context.** Each saved attempt shows its recorded date and time. Expandable details include the original facts and self-checks, application question and response, application self-check, and revision draft. A learner can continue a specific older compatible plan; edits update that record rather than creating a new recall attempt.
- **Changed facts are clearly historical.** Attempts whose facts no longer match are labeled “Earlier facts — review only.” Their original notes remain readable, but resuming against different facts is unavailable. Resumed plans also explicitly say they are saved practice rather than a new recall.
- **Overlapping saves preserve work.** Revising a completed self-check changes only its checks in the latest stored record. Committing a goal patches its revision fields, retaining newer application text and review dates. Missing/deleted records remain protected from ordinary follow-up patches. A learner can explicitly retry the first save of a fresh attempt, while tombstoned attempts remain deleted. An old asynchronous save cannot navigate away from a newer recall session.

The added revision draft belongs to the existing private browser/profile practice store. It is excluded from shared responses, text backups and print presets, like the other private practice evidence. The added field is optional for older saved attempts.

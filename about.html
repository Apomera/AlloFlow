Privacy and deployment

What the project does—and does not—promise

Local-first options

AlloFlow includes browser-based classroom workflows and a Desktop path designed to support local AI backends. Core local workflows can run without required student accounts or required personally identifiable information.

Provider choices still matter

Some optional workflows can use external AI providers. Data handling, account requirements, costs, and provider terms depend on the path a school chooses and configures.

Schools verify their deployment

AlloFlow does not make blanket legal-compliance claims. Schools and districts should evaluate their configuration, policies, contracts, consent needs, and applicable requirements.

Cost boundary: AlloFlow's source code is free under the AGPL v3 and does not require an AlloFlow software subscription. Devices, hosting, connectivity, and any optional third-party AI services can still have their own costs.

Direct answers

Common questions about AlloFlow

What is AlloFlow?

AlloFlow is a free, open-source AI classroom assistant and instructional differentiation engine for educators, learners, families, specialists, and school teams. It combines UDL, accessibility, AAC communication, STEM, SEL, document support, and local-first deployment paths.

Is AlloFlow free and open source?

Yes. The source code is published under the GNU AGPL v3. Optional infrastructure or third-party services may have separate costs or terms.

Does AlloFlow require student accounts?

No. Core local classroom workflows can run without student accounts or required personally identifiable information. A school's chosen deployment and AI provider can introduce separate requirements.

Where is the latest official version?

Use the Apomera/AlloFlow repository and its release page. The current maintained release is version 1.2.

Is AlloFlow affiliated with Google?

No. AlloFlow is an independent open-source project and is not affiliated with Google. Some deployment paths can use Google-managed services when a user or organization chooses them.

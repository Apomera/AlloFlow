- **Geometry World exports now pass Print Lab's own preflight as one closed solid (2026-09-06, second pass).** The throwaway probes from the pass below became a documented tool, `dev-tools/geometry_world_gl_probe.mjs`, which mounts Geometry World on real WebGL, places blocks through the engine, and can run any script inside the page. Its first job was to load `printable_model_module.js` alongside the tool and run Print Lab's `inspectStl` on the bytes the hand-off actually sends. Pure cubes passed. A slab on a cube came back WARN with 4 non-manifold edges and no enclosed volume; the 12-block mixed build, 17. The reason is structural: every block is exported as its own closed shell, so two neighbours keep a coincident, opposite-facing pair of faces between them, and the old rule dropped that pair only when both were cubes. A slicer merges such shells, but the preflight counted every shared edge as needing review, in the tool that exists to teach those shapes. The exporter now drops a face wherever both neighbours present the same polygon on their shared cell boundary (same corner points, same area, opposite normals), decided from the triangles themselves so there is no shape table to keep in step with the geometry. Re-measured: the slab on a cube and the whole mixed build both PASS with zero open, non-manifold or mis-wound edges, one shell, and an enclosed volume of 1,218.75 mm³ for the mixed build, which is exactly 9.75 cubic units at 5 mm per block. Three separate stacks correctly report three shells; the hand-off only ever sends one connected build, so that warning cannot reach a student. The Menu's own '3D Print' download was a second copy of the older rule; it now routes through the same surface function when the builder is loaded, keeping one derivation, with the old rule as a fallback for a host without the builder. Gated three ways: a pure unit test of the face-matching rule (identical square with a different triangulation is dropped; a half-height rectangle against a full square is kept; an unselected neighbour never culls), a WebGL test that exports a slab, a diagonal half and a quarter wedge each standing on a cube and asserts Print Lab's preflight reports PASS, one shell and the exact enclosed volume, and a probe that presses the Menu button and inspects what it downloads.

## Deployment boundary

These are local source and packaged-file improvements. Updating this repository does not update an existing Apps Script deployment. Publish a new version of the school-owned deployment after copying the updated package files. Existing schema-v6 repositories need no schema migration for these changes; older repositories must follow the documented migration order.

SIS support is an approved JSON snapshot workflow, not a live vendor connection. Printer actions record workflow status; they do not send commands to a printer. Guardian consent and physical print review remain school responsibilities.
